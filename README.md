# 🖧 Computer Networks Lab

- Welcome to the Computer Networks Lab repository!
- This collection of labs covers essential networking concepts including basic routing, subnetting, VLANs, and dynamic routing protocols like RIP.
- Each lab contains a unique topology, a structured explanation, and step-by-step configuration guidance.
- From lab 7 we will be focusing on packet capturing, analyzing network traffic, and understanding protocols at different layers.

---

## 📁 Lab Index

| Lab | Title                                                          | Concept Focus              |
|-----|----------------------------------------------------------------|----------------------------|
| 1   | Basic Inter-Network Communication using Routers and Switches   | Static Routing             |
| 2   | Multi-Network Communication using Static Routing               | Multi-Router Topology      |
| 3   | Redundant Routing Path using Static Routes (Triangle Topology) | Redundancy, Static Routing |
| 4   | Dynamic Routing with RIP in a Triangle Topology                | Dynamic Routing (RIP)      |
| 5   | Subnetting a Class A Network into 4 Subnets                    | Subnetting                 |
| 6   | Inter-VLAN Communication using Router-on-a-Stick               | VLANs + Inter-VLAN Routing |

---

## 🛠️ What we have done so far

- Setting up basic LANs and interconnecting them with routers  
- Configuring static and dynamic routing (RIP)  
- Designing subnetted networks using Class A IP blocks  
- Implementing VLANs and router-on-a-stick for inter-VLAN routing  
- Structuring real-world topologies using switches and routers
